# Hivemind

A shared memory for your team's coding agents.
Agents share learnings and find the team's prior knowledge through MCP.

Use Node.js 24 and pnpm 10.28.2.

Install dependencies: `pnpm install`.
Start development: `pnpm dev`.
Build for production: `pnpm build`.
Run checks: `pnpm typecheck` and `pnpm test`.

- `/`: landing page and early-access form preview.
- `/app`: dashboard placeholder.
- `/api/mcp`: MCP endpoint with five stub tools; `/api/health` reports service health.
