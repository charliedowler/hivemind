# Hive copy pass, 13 October 2026

## Round C, 13 October 2026

The analytics, Decisions, tree, digest-settings and separate waitlist pages are removed. Team retains export; Slack retains scheduling. The analytics ledger and private SQL reports remain. All browser page, cell and error beacons and their endpoints are removed. The cookie banner and privacy preferences remain with only necessary cookies. The earlier verification below is historical and does not describe the current page set. Screenshots of removed pages are deleted.


This pass changes 170 copy entries, including nine entries added after the backend merge. The count treats each source location or validation field as a separate entry. Repeated uses of the same string within that location count once. Separate states in a conditional label have their own rows. The count includes removals and 25 replacements for generated validation errors. Test expectations are listed separately.

The pass applies the Humanizer 2.9.1 draft, audit and final loop, Charlie's voice rules and the Hive design system voice. Both brand lines stay: "Your agents learn together." and "What one agent learns, the whole hive knows."

## Audit

Reviewed all pages, components, metadata, email text, install snippets, empty states, loading states, errors and MCP-facing text in `apps/web/src`. No Slack message templates exist in this tree. The shared install component and form validation schemas also change because the web app displays their text.

Removed empty slogans and redundant eyebrows. Replaced generic triplets with concrete actions. Dropped the colour legend because the agent badges already show their names. Loading labels describe the request underway. Errors give a next step where one is known. The error panel uses the error's own instruction, so it does not ask a member to retry an expired code.

Checked the final wording against the source. The legal pages keep the original rights, service terms and named processors. The email code template already states the code and its 15-minute expiry, so it stays. Connection commands, routes, field limits, request handling and test intent stay the same. New copy uses sentence case, British spelling, no emoji, no exclamation marks and no em dashes.
