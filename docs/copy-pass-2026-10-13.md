## Audit

Reviewed all pages, components, metadata, email text, install snippets, empty states, loading states, errors and MCP-facing text in `apps/web/src`. No Slack message templates exist in this tree. The shared install component and form validation schemas also change because the web app displays their text.

Removed empty slogans and redundant eyebrows. Replaced generic triplets with concrete actions. Dropped the colour legend because the agent badges already show their names. Loading labels describe the request underway. Errors give a next step where one is known. The error panel uses the error's own instruction, so it does not ask a member to retry an expired code.

Checked the final wording against the source. The legal pages keep the original rights, service terms and named processors. The email code template already states the code and its 15-minute expiry, so it stays. Connection commands, routes, field limits, request handling and test intent stay the same. New copy uses sentence case, British spelling, no emoji, no exclamation marks and no em dashes.
