How do we run migrations on a preview branch?

Use the direct connection, not the pooler. Set DIRECT_URL on the preview environment and run pnpm db:migrate before the build step.1

The pooled URL drops the advisory lock the migrator holds, so the run looks fine and then applies nothing.2
